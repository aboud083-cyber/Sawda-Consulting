# Sawda Consulting

Site vitrine statique en français. Il présente les offres de conseil numérique, d’automatisation et de création d’agents IA, ainsi que trois démonstrations interactives.

Ouvrez `index.html` dans un navigateur ou lancez `python3 -m http.server 8000` depuis ce dossier, puis ouvrez http://localhost:8000.

- `index.html` contient la page et les scénarios.
- `style.css` définit la mise en page et les couleurs.
- `script.js` gère les démonstrations et prépare un brouillon d’e-mail depuis le formulaire.
- `images/` contient les quatre photographies.

Le site peut être hébergé sur un serveur statique. Le visiteur envoie lui-même le brouillon depuis sa messagerie.
